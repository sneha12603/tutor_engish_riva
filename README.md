# 🎙 Riva — AI English Speaking Tutor

A free AI-powered English speaking tutor inspired by **PW Talk's Riva**, 
built using open-source tools and free APIs.

## ✨ Features
- 🎙 Voice input — speak freely, no time limit
- 🤖 Real-time grammar correction
- 🔊 AI voice replies back
- 💬 Chat history maintained
- 📱 Works on mobile and desktop

## 🛠 Tech Stack
| Tool | Purpose |
|---|---|
| Whisper (Groq) | Speech to Text |
| LLaMA 3 (Groq) | AI Brain |
| gTTS | Text to Speech |
| Streamlit | Web UI |

```bash
git clone https://github.com/sneha12603/tutor_engish_riva
cd tutor_engish_riva
pip install -r requirements.txt
streamlit run app.py
```
